# CONTRIBUTING.md

## Быстрый запуск

Запускайте команды из корня репозитория.

**Локальная сборка**

Обновляет только папку `conf/`.

```bash
./tools/build-shadowrocket-conf.sh
```

**Полная сборка**

Обновляет `conf/`, `rules/`, `modules/` и `scripts/`.

Запускает сборку в GitHub Actions для версии текущей ветки в `origin` и скачивает артефакты в рабочую копию.

```bash
./tools/preview-artifacts.sh
```
