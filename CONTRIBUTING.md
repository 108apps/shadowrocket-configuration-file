# CONTRIBUTING.md

Если вы меняете конфиги Shadowrocket или GitHub Actions, ознакомьтесь с [инструкцией по сборке](docs/build.md).<br>
В ней описаны локальная сборка профилей, предпросмотр артефактов, проверка workflow и источники доменных списков.

При диагностике сборки сверяйтесь со списком [известных проблем](docs/build-issues.md).
