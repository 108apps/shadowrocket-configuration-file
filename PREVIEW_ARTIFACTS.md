# Как посмотреть diff сгенерированных файлов

Из корня проекта запусти [скрипт предварительного просмотра](.github/preview-artifacts.sh):

```bash
.github/preview-artifacts.sh
```

Через GitHub CLI (`gh`) скрипт запустит `build-artifacts.yml` для текущей ветки в репозитории `origin`. GitHub собирает версию ветки, отправленную в `origin`, поэтому изменения генератора нужно предварительно закоммитить и отправить.

После успешной сборки скрипт скачает артефакт `shadowrocket-files` именно из этого запуска и распакует его во временную папку. Затем он скопирует файлы в `conf/`, `modules/`, `rules/` и `scripts/` в корне проекта. В конце `git status --short` покажет изменённые и новые файлы, а `git diff` — изменения в отслеживаемых файлах.

Если в этих четырёх папках уже есть локальные изменения или новые неотслеживаемые файлы, скрипт остановится до запуска сборки.
