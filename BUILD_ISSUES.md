# Известные недостатки сборки

- Сбой загрузки списка для профиля `mini` может остаться незамеченным, а параллельные сборки профилей конфликтуют из-за общего `conf/General.tmp`. Оба случая описаны в [TODO.md](TODO.md).
- Composite action использует `bash -e` без `pipefail`. Если последняя команда конвейера успешна, ошибка более ранней команды может остаться незамеченной. Перед изменением режима нужно проверить случаи, в которых пустой результат фильтрации допустим.
- ShellCheck сообщает `SC2155` в [локальном скрипте сборки](tools/build-shadowrocket-conf.sh). Вызов `brew --prefix` внутри `export` может скрыть код ошибки. Для семи генераторов профилей ShellCheck нужен явный параметр `--shell=bash`, поскольку они запускаются через Bash и не имеют shebang.
