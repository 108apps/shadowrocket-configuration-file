# Известные проблемы сборки

## Сбой загрузки списка для профиля `mini`

В `tools/profiles/sr_ru_mini.sh` результат `curl -s` передаётся в `awk`. При сбое загрузки `./tools/build-shadowrocket-conf.sh` может завершиться с кодом `0`. В таком профиле отсутствуют правила из `community.list`, трафик, который должен был совпасть с ними, может попасть под `FINAL,DIRECT`, а workflow может опубликовать профиль. Поведение унаследовано от прежней сборки.

Для исправления нужно обработать сбой загрузки и завершить сборку с ошибкой.

## Конфликт одновременных локальных сборок

Все генераторы используют `conf/General.tmp`. Локальный скрипт запускает генераторы последовательно в рамках одного процесса. При двух запусках в одном каталоге один процесс может заменить шаблон или удалить его во время работы другого.

Для исправления можно собирать профили в отдельном временном каталоге каждого запуска и переносить готовые файлы в `conf/` после успешной генерации.

## Ошибки в конвейерах composite action

Composite action использует `bash -e` без `pipefail`. Если последняя команда конвейера успешна, ошибка более ранней команды может остаться незамеченной. Перед изменением режима нужно проверить случаи, в которых пустой результат фильтрации допустим.

## Проверка скриптов в ShellCheck

ShellCheck сообщает `SC2155` в [локальном скрипте сборки](../tools/build-shadowrocket-conf.sh). Вызов `brew --prefix` внутри `export` может скрыть код ошибки. Для семи генераторов профилей ShellCheck нужен явный параметр `--shell=bash`, поскольку они запускаются через Bash и не имеют shebang.
